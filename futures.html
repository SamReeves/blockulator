❓ How Gaussian Futures Work

  1. Create a Future: Set a target value and expiration time
  2. Gaussian Distribution: Values follow a normal distribution curve
  3. ERF Calculation: The error function determines probabilities on-chain
  4. Time Decay: Value changes as the future approaches expiration
  5. Settlement: Futures settle based on final value at expiration
