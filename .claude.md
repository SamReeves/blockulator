# Claude AI Assistant Instructions

## Project-Specific Rules

### Contract Addresses - DO NOT AUTO-MODIFY

**NEVER automatically edit, modify, or update the following files:**

- `contracts/deployments/addresses.js`
- Any contract address configuration files

**Reasoning:**
- Contract addresses are critical infrastructure
- Manual review and verification is required for all address changes
- Automated updates could cause production issues

**What to do instead:**
- Provide the user with the address to copy
- Show them the exact line to update
- Let them manually verify and update addresses.js
- The `update-addresses.sh` script is available if they choose to use it

### Deployment Workflow

The deployment utilities are:
1. `compile-and-prepare.sh` - Compiles Vyper contracts
2. `deploy.html` - MetaMask-based browser deployment (no backend)
3. `update-addresses.sh` - Manual utility to update addresses (user's choice)

All deployment is done locally with MetaMask. Never suggest remote deployment or automated address updates.

## General Guidelines

- Preserve user's manual control over critical configuration
- Always show what needs to be changed, let user decide when/how to apply it
- Contract deployments are high-stakes, require explicit user action
